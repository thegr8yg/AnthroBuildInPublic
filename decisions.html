AnthroBuildInPublic — Decision Log

22 May 2026

This file is a hidden artifact. It is not linked from the site and exists only in the repo. It records every design and architectural decision made (or explicitly rejected) during the retention/audacity redesign.

Decisions Made

THEME 5 theme variants from 4 perspectives
1. Aurora (derived from original): Keeps the purple aurora but amplifies it with bolder typography, tighter spacing, and a floating glassmorphism ticker. This is the default.
2. Editorial: High-contrast serif/display pairing, magazine-style grid, massive whitespace, task cards feel like editorial blocks. Perspective = content-first typography.
3. Brutalist: 1px black borders, no border-radius, system monospace font, raw checkboxes, exposed metadata. Perspective = anti-design/raw authenticity.
4. Midnight: Deep dark canvas, reduced chrome, purple glow accents only on hover. Perspective = immersive focus/night-mode.
5. Kinetic: Cards float with subtle parallax, smooth scroll snapping, animated gradients. Perspective = motion and liveliness.
MOBILE Horizontal scroll-snap carousel for buckets on mobile
On screens below 640px the 4-column board collapses to a single full-width carousel with CSS scroll-snap-type. Each bucket is a "slide". This preserves the spatial metaphor of columns while respecting narrow viewports. Auto-hide scrollbar, snap to start, next/prev optional dots.
RETENTION Email capture popup overlay
A modal appears after 8s of engagement (or on first visit) offering to join the build-in-public email list. Dismissal is stored in localStorage for 14 days. Uses a soft backdrop blur and a single email input. This is intentionally lightweight so it does not fight the minimalist ethos.
SUPABASE Scaffolded /api/subscribe route + Supabase client stub
The user explicitly asked to scaffold but not implement the Supabase connection. Created a POST route that validates email format and returns a friendly "not configured yet" message. The Supabase client initialization is commented out with instructions. This lets the user plug in credentials later.
NOTION Preserve existing Notion integration, add visual polish
The existing /api/tasks route is robust. We kept it as-is but added a small Notion attribution link in the footer and a "Synced from Notion" tooltip on the live badge. This reinforces trust in the real-time mirror without adding clutter.
AUDACITY Added theme switcher, bolder hero, animated gradient text
To make the site feel audacious without breaking minimalism: the hero title uses a subtle animated gradient text fill in Aurora mode; the Brutalist mode strips all softness; the Kinetic mode makes the board feel alive. These are opt-in via the theme switcher, so the default experience remains calm.
ACCESSIBILITY Reduced motion respected, focus states maintained
All animations check prefers-reduced-motion. The popup traps focus while open. The carousel uses semantic buttons for navigation. Theme changes apply instantly without page reload.

Decisions Explicitly Not Made / Rejected

REJECTED No full-page background video or WebGL
Would hurt performance and contradict the minimalist focus. The aurora CSS gradient is enough visual interest.
REJECTED No sidebar navigation or mega-menu
This is a single-page board. Adding navigation would dilute the to-do list focus. All actions (theme, email) are inline or in overlays.
REJECTED No full task detail pages
The current task cards show all relevant info at a glance. Expanding into detail pages would move away from the dashboard/board metaphor and increase complexity unnecessarily.
REJECTED No dark-mode toggle separate from themes
Midnight theme already covers the dark aesthetic. A separate toggle would create a matrix of states (theme × mode) that is hard to maintain. Users who want dark can pick Midnight.
REJECTED No drag-and-drop reordering
The source of truth is Notion. Allowing DnD on the public mirror would create a false expectation that changes persist. The read-only mirror is a feature, not a bug.
REJECTED No analytics dashboard or heavy tracking
Vercel Analytics is already included. Adding more tracking scripts would hurt performance and privacy. Retention is driven by design and content, not surveillance.
THEME Paper — tactile warm aesthetic
Warm cream background with subtle dot-grid paper texture (CSS radial-gradient), Georgia serif type, dashed borders, ink-colored text. No aurora. Feels like a physical task list on heavy paper. Perspective = analog/tactile minimalism.
THEME Terminal — retro CRT phosphor aesthetic
Pure black canvas, phosphor-green text, monospace everywhere, repeating CSS scanlines, glowing hover shadows. All chrome stripped to lines and blocks. Perspective = retro-computing/raw data. No aurora; scanlines overlay the entire viewport.
